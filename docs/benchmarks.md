# Benchmarks

Generated by `node bench/run.mjs` on 2026-11-06. Each row is the median of 3 runs of the real CLI
(`reachgate explore <target> --json --quiet`) in a child process. States, steps and findings are
deterministic for a given seed and budget; times and memory depend on the machine.

| Load average at start | 8.38 8.10 5.74 |
| Peak RSS | Node: /usr/bin/time -f %M on the CLI process for JS targets, process.resourceUsage().maxRSS inside the CLI for Python targets (Node only). Python adapter: getrusage(RUSAGE_SELF) inside the adapter process (bench/py_rss.py). |

Columns: **deepest** is the longest trace explored. **Stopped by** is `exhausted` when every reachable state was visited (BFS) or the budget that
ran out. **First violation** is the time (and steps) until the first invariant violation was seen;
**witness** is that violation's trace length (shortest for BFS, 1-minimal after shrinking for Go-Explore).
